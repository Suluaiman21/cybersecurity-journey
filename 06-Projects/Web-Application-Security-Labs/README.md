
# Web Application Security Labs

## Overview

This project documents hands-on web application security testing performed in controlled vulnerable environments.

The labs were conducted using **Damn Vulnerable Web Application (DVWA)** and **OWASP Mutillidae II** to develop practical understanding of common web application vulnerabilities, their security impact, and basic mitigation techniques.

## Labs Completed

| Lab               | Platform            | Vulnerability             |
| ----------------- | ------------------- | ------------------------- |
| Command Execution | DVWA                | Command Execution         |
| File Upload       | DVWA                | File Upload Vulnerability |
| SQL Injection     | OWASP Mutillidae II | SQL Injection             |

## Objectives

* Develop practical web application security testing skills
* Understand how common vulnerabilities occur
* Practice identifying and validating vulnerabilities in controlled environments
* Compare security controls and their effectiveness
* Understand the potential impact of successful exploitation
* Learn appropriate defensive and mitigation techniques
* Document hands-on cybersecurity work for future reference

## Tools & Technologies

* DVWA
* OWASP Mutillidae II
* Burp Suite
* Web browsers
* Linux / virtualized lab environment

## Key Learning Areas

* Command execution vulnerabilities
* Unrestricted or improperly validated file uploads
* SQL injection
* Input validation
* Security controls
* Secure coding and mitigation
* Web application security testing methodology

## Disclaimer

All testing documented in this repository was performed against intentionally vulnerable applications in a controlled lab environment for educational and cybersecurity training purposes.

No unauthorized systems or applications were targeted.
